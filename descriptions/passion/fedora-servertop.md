fedora-servertop is the repo I opened to document a server of my own. The
README states the whole idea in one line: "A collection of photos and
documentation of my journey in owning everything. My own server for
anything you can think of." The name is the only hint at the shape of the
thing, "fedora" for the distribution and "servertop" for a machine meant
to be a server and a desktop at once, and the repo spells out neither.

## Where it stands

This is a placeholder, and I would rather label it as one than dress it
up. The repository has exactly one commit ("Initial commit", 4 May 2026)
on `main`, its only branch, and that commit adds one file: a 140-byte,
two-line README. No photos, no documentation, no configs, no scripts.
Nothing has been pushed in the four months since.
