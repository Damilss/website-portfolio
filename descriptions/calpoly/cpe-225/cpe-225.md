CPE 225 is Cal Poly's computer organization course. The through-line across
these assignments is the same one: take a program that would be a few lines of
C and write it again in RISC-V assembly against the RARS simulator, until the
machine-level cost of every construct is obvious.

## What's in here

- **cpe-225-asgn2** — CountOnes: a set-bit counter written in C, then
  hand-translated to assembly under a no-subroutines constraint.
- **cpe-225-asgn3** — a nine-operation integer calculator, split across three
  assembly units with named wrapper routines around `ecall`.
- **cpe-225-asgn4** — string routines: `strlen`, `strcmp`, and a console
  `readstring`. Left unfinished, and the page says where it stops.
- **cpe-225-asgn6-mmio-interrupts** — the last one: replacing system calls with
  routines written against the device registers themselves, then driving them
  from a keyboard interrupt handler.

Open any file in this folder to read the full writeup.
