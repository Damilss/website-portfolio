Computer Engineering at California Polytechnic State University, San Luis Obispo
(B.S., class of 2029). This folder collects the coursework — the labs,
assignments, and projects from each class — along with the work that happens
around it: a club firmware project and a teaching role.

## What's in here

- **cpe-225** — Computer Organization. C programs hand-translated into RISC-V
  assembly, ending with memory-mapped I/O and interrupt handling.
- **csc-101** — Fundamentals of Computer Science, in Python.
- **csc-202** — Data Structures: sorting, graphs, and the algorithms over them.
- **csc-203** — Project-Based Object-Oriented Programming, in Java. The largest
  folder here.
- **csc-2050** — Software System Mechanics: the Linux command line and shell
  scripting.
- **fsae** — Cal Poly Formula SAE. Software and firmware work for the team.
- **generational-wealth-inequality** — a one-page site publishing a four-person
  ENGL 133 research essay.
- **isa-cs101** — my Instructional Student Assistant role for CS 101.

Open a folder to browse its assignments, or open a file to read the writeup.
