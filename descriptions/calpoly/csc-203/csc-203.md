CSC 203 is Cal Poly's project-based object-oriented programming course, taught
in Java. The labs build the vocabulary — classes and static state, inheritance,
comparators — and the projects apply it at a larger scale, once by rebuilding
the same simulation under a different design and once by refactoring someone
else's codebase.

## What's in here

- **csc203-lab2** — classes, fields, and static state.
- **csc203-lab3** — an abstract base class and subclasses. Left unfinished.
- **csc203-lab4** — `Comparable` and standalone `Comparator`s.
- **csc203-project1** — a two-person slice of a class-wide weekly-calendar CLI.
- **csc203-project2-3** — a Rock Paper Scissors simulation, built once with
  standalone classes and then rebuilt around an interface and a superclass.
- **csc203-project4** — refactoring an instructor-provided Processing grid-world
  from enum-switched classes into a cohesive type hierarchy.
- **csc203-project5** — Streams, lambdas, and custom exceptions over a dog-breed
  CSV, plus an OpenAI chat client.
- **csc203-final-review** — a scratchpad from studying for the final.

One more repository, `csc203-keyExtr`, was created for key-extractor practice
and never got past an empty scaffold, so it has no page here.
